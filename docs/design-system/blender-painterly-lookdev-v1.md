## 2. Blender 表面規格

- Eevee Next、正交攝影機、35-40 度俯視。
- Standard 色彩轉換；不得使用 ACES、Filmic、Bloom、暗角或電影調色。
- 大面材質 `metallic = 0`、`roughness >= 0.88`，高光寬、柔、暗。
- 以 1.0-1.4 px 暖灰棕線條呈現主要輪廓；不得使用純黑線。
- 幾何至少有 1.5-4 cm 倒角，避免原始方塊感；倒角不得改變 SKU 占地尺寸。
- 即時 GLB 使用純色霧面 PBR；手繪筆觸只可用低解析、可壓縮且無方向漂移的貼圖。
- 生活小物放在 `Lifestyle_Dressing` collection，不參與商品碰撞、計價或 SKU 外觀比對。

## 3. 光線規格

- 世界光為中性象牙白，主要光源為大面積、柔和、近乎無影的日光。
- 只保留短而淺的接觸陰影；環境暗部不得低於主要表面約 65% 明度。
- 白牆維持中性象牙白，不以黃色燈光製造溫馨感。
- 溫馨感來自淺木、燕麥布料、鼠尾草綠、植栽及生活用品。

## 4. 造型規格

- 可購買家具必須保留實際外框尺寸、椅高、座深與主要結構辨識。
- 沙發、椅墊、桌角可圓潤化，但不可變成無結構的軟糖或玩具。
- 每件核心家具使用 3-6 個命名材質，所有系列共用同一色票。
- 原創住民採圓石／雲朵般輪廓，不使用任何既有動漫角色的耳朵、五官、服裝或標誌。

## 6. 直接退件條件

- 牆或家具出現原始幾何方塊感、塑膠高光或不一致材質。
- 大面積橘黃偏色、黑背景、長投影、重 AO 或暗部糊成一片。
- 為追求可愛而改變 BH7 開口、家具占地或 SKU 比例。
- 生活小物與商品合併成同一 mesh，導致選取、碰撞或購物車無法區分。
- 只輸出渲染圖，沒有 `.blend`、GLB、命名 collection 與驗證報告。
