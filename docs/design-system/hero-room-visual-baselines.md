# Hero Room 固定視角驗收基準

狀態：正式 V2 驗收規格

視覺版本：`v2-original-cozy`

格局資料：遠雄樂元 BH7 A6，來源與量測依 `docs/assets/bh7-floorplan-source-audit.md`

## 固定輸入

- 視口：桌面 `1440×900`，iPad 橫向 `1180×820`。
- 主題：`晴日奶油`。
- 家具：地毯、雲朵沙發、矮桌、扶手椅、落地燈、植栽與收納櫃；位置來自同一份 `SceneSnapshotV1`。
- 主角：居遊所原創非人類住民；體型、輪廓、呼吸速度不因模式而換畫風。
- 材質與光影：高明度霧面、低對比粉霧藍輪廓；不允許 ACES、Bloom、暗角、重 AO、深色投影或 `ContactShadows`。

## 五個必測狀態

| 狀態 | 固定呈現 | 通過條件 |
|---|---|---|
| `hero` | A6 客餐廳、相機目標 `[-1.68, 0.52, -0.70]`、zoom `96` | 主家具群與住民均在畫面主角區，房間不得變成灰暗建築鳥瞰圖 |
| `whole` | A6 全屋、使用戶型 runtime 相機 | 所有邊界、牆、門窗與家具位置可同時檢查，切換不改快照 |
| `audit` | 全屋、PDF 平面圖覆疊、不顯示住民 | 精準幾何與 PDF 對位；表現層不得影響審核 |
| `explore` | 相機跟隨住民，zoom 為 A6 runtime 的 `1.72×` | 主角可讀、特寫不穿牆；牆高封頂不超過 `1.9m` 的視覺切面 |
| `selected` | 同 `hero`，選取一件商品 | 商品資訊、價格、旋轉、刪除、復原與重做仍可用 |

## 分層規則

`FloorplanColliders` 是唯一的物理真相，同時供審核與正式呈現使用。`AuditFloorplan` 只負責格局溯源；`PresentationFloorplan` 只負責童趣比例、高明度色彩和導覽。任一呈現修改若造成快照、碰撞或 PDF 對位改變，即視為失敗。
