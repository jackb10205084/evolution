## 不可漂移的 Style Bible

- 原創非人類居民：奶油色糰子輪廓、小圓耳、點狀深棕眼、淡桃腮紅、小嘴、短腳、珊瑚色斜背小包。
- 同一居民不得在不同畫面改變臉型、毛色、身體比例、配件或物種特徵。
- 2.5D 圓糯卡通：低多邊形結構、稀疏暖灰棕輪廓、大片霧面粉彩色塊、極低對比與輕微手繪抖動。
- 光影固定為高明度漫射光；禁用方向性金色光束、深色投影、重 AO、強接觸陰影、光滑塑膠、強反射 PBR、Bloom 與電影級寫實。
- 色盤：牛奶白、香草奶油、淡奶油黃、腮紅蜜桃、薄荷綠、粉霧藍灰；木色只作輔色，不得支配整個畫面。
- 建築尺寸、商品 footprint 與碰撞器必須準確；視覺網格可將圓角、軟墊飽滿度、桌板厚度與腳徑 Q 版化 15–25%，不得改變商品功能與可辨識特徵。
- 家具造型規則：圓角、厚軟墊、短而略粗的腳、減少細碎刻線；每件商品最多保留 2 個接近的明度階，不以陰影塑造寫實體積。
- 所有場景小物優先使用可購買的生活用品。
- 不使用或模仿任何現有角色、遊戲 UI、圖示、音效、Logo 或品牌話術。

## A6 Hero Room 建築優先順序

1. 以建商 A6 正式平面圖、隔間尺寸圖與立面圖重建空間殼體；Key Art 不作尺寸依據。
2. 鎖定玄關、餐廚帶、客廳、陽台開口、多功能室通道、門窗與固定櫃體。
3. 先完成日光慢生活單一主題；其他主題只驗證材質與燈光切換。
4. 家具核心組：SALTSJÖBADEN 雙人沙發、BORGEBY 圓桌、EKENÄSET 扶手椅、STOENSE 地毯、LAUTERS 落地燈、KALLAX 層架、FEJKA 植栽。
5. 每件商品建立精準 footprint/collider 與 Q 版視覺模型；商品卡保留官方照片、尺寸與來源狀態。
6. 角色、家具、建築共用同一套暖灰棕輪廓、二階近明度色塊、無 AO 的漫射光與粉彩色彩管理。

## Tripo Studio → Blender 正式管線

1. 建築殼體不交給生成式 3D 猜測；依 A6 正式圖於 Blender 以公尺重建牆體、門窗、固定櫃體與開口。
2. Tripo Studio 第一批只生成可移動資產：原創居民、雙人沙發、圓茶几、扶手椅、落地燈、層架與植栽。
3. 每個資產以正式母版的正面／四分之三視角與獨立文字規格生成，不把整張房間圖直接轉成單一不可編輯模型。
4. 生成結果回 Blender 重拓樸、校正實際尺寸、拆分材質、建立 pivot、碰撞器與 LOD；AI 輸出不得直接上線。
5. 共用材質限制為霧面 Base Color；金屬與玻璃僅保留商品辨識所需的最低反射，不使用烘焙重陰影貼圖。
6. 第一批單件資產驗收通過後才批次生成，避免消耗額度並防止畫風漂移。

## Hero Room 視覺驗收

- 固定 35-45 度正交模型屋鏡頭；平移、縮放與 90 度轉向不破壞構圖。
- 3D 畫面需能一眼對應正式母版 `09` 的粉彩色盤、圓潤輪廓、低陰影、居民比例與物件密度。
- A6 牆體、門窗、固定櫃體及可用面積以正式圖驗證。
- 自有或模擬商品經 Q 版轉換後仍可辨識，且 footprint 與售價資料不受美術變形影響。
- 主場景畫面占比至少 75%；商品庫與操作介面不得壓縮 Hero Room。
- 桌面目標 60 FPS、iPad 30 FPS；使用相同美術，僅調整 LOD、陰影與貼圖解析度。
- 首件居民、沙發及茶几未通過同場驗收前，不批次產生其餘正式 3D 資產，也不覆蓋現行上線版本。
